# お気に入りの写真

## いちばん簡単な方法：管理パネル

Mac で **http://localhost:8787/favorites** を開くと、項目ごとに「写真を選ぶ」から
Mac の写真を指定できる。保存すると下と同じ処理（正方形に整えて `images/` に入れ、
`items.json` の `img` を設定）が自動で走る。項目の追加・編集・並べ替えも同じ画面でできる。
（パネルは `~/Claude/musings-tools/panel_server.py`。常時起動している）

以下は、コマンドで何枚もまとめて取り込みたいときのやり方。

## 置き方（まとめて取り込む）

1. 写真を `images/_inbox/<slug>.jpg` に置く
   - `slug` は `items.json` の各項目に入っている。一覧は下のコマンドで出る
   - 拡張子は `.jpg` `.png` `.heic` `.webp` などそのままでよい（iPhone の HEIC も可）
2. 取り込む

```bash
cd ~/Claude/favorites && python3 add_images.py
```

3. 短辺を 1000px に合わせて中央を正方形に切り抜き、`images/<slug>.jpg` になる。
   `items.json` の `img` も自動で設定される
4. 確認して `git add -A && git commit && git push`

slug の一覧と、写真が入っているかの確認:

```bash
cd ~/Claude/favorites && python3 add_images.py --list
```

## 決めごと

- **非公開という状態は持たない。** `items.json` は公開リポジトリに入り、
  `https://m-note.uk/favorites/items.json` で誰でも全文を読める。
  表示上だけ隠す仕組みは「隠したつもりで隠れていない」状態になるので作らない。
  **公開していいものだけを書く。** 人に見せたくないものは、そもそもここに書かない
  （書くなら vault など私的な場所へ）
- **自分で撮った写真だけを置く。** 製品写真やメーカーのサイトの画像、他人の写真は
  公開サイトに載せない（著作権）。フッターにも「写真は自分で撮ったものだけ」と書いてある
- 正方形に切り抜かれるので、**真ん中に主役が来るように**撮っておくと扱いやすい
- 写真が無い項目は、頭文字のプレースホルダーが出る。**一枚ずつ増やしていけて、
  途中でも見た目が崩れない**
- サービス（ChatGPT、Netflix など）はロゴになってしまうので、無理に入れなくてよい。
  他社のロゴを載せるのは避ける
- 撮影が難しい場所（ジムの浴室など）も、無理に入れない
- 写真を外したときや項目を消したときの写真は、パネルが `images/_removed/` へ移す。
  このフォルダは push されない（消さずに取っておくだけ）

## 写真がないとき

写真は必須ではありません。**url とひとことだけで登録してよい**ようにしてあります。
`url` を書くと、カードの名前がその外部リンクになります（http / https のみ）。

```json
{ "title": "ご飯を炊く土鍋", "memo": "炊飯器ではなく土鍋で炊く。", "slug": "donabe",
  "url": "https://example.com/..." }
```

写真を撮る手間で登録が止まるより、まず名前とリンクだけ入れておいて、
撮れたときに `_inbox` へ置くほうが続きます。

## 手で書く場合

スクリプトを使わず、自分で正方形の画像を用意して `images/` に置き、
`items.json` に直接書いてもよい。

```json
{ "title": "RICOH GR III", "memo": "カメラ。", "slug": "ricoh-gr3", "img": "images/ricoh-gr3.jpg" }
```
