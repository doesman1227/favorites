# お気に入りの写真

ここに自分で撮った写真を置き、`items.json` の各項目に `"img": "images/<ファイル名>"` を足すと
カードに表示されます。足していない項目は、頭文字のプレースホルダーが出ます。

- 形式: `.jpg` / `.webp` / `.png`
- 正方形に切り抜かれて表示されるので、真四角に近いものが扱いやすい
- ファイル名は英数字のケバブケース（例: `rikoh-gr3.jpg`）
- **自分で撮った写真だけを置く。** 製品写真や他人の写真は公開サイトに載せない

例:

```json
{ "title": "RICOH GR III", "memo": "カメラ。", "img": "images/ricoh-gr3.jpg" }
```
